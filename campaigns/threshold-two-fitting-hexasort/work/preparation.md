# Prepare evidence

Prepared 2026-09-26. The fixed corpus contains 120 distinct 3-SAT formulas: 20 hand cases and 100 seeded random cases, with 64 YES and 56 NO. Formula sizes range from 0 to 6 variables. `generate_cases.py` fixes inputs and seeds before any candidate construction.

Run `uv sync --locked` and `uv run --locked python campaigns/threshold-two-fitting-hexasort/work/check.py --self-test`. It first runs the copied `research/validate_preparation.py`, regenerates random formulas, recomputes Z3 source labels, directly validates assignments and compares with exhaustive Boolean assignments. The target oracle recursively tries each empty vertex for each next stack and applies the threshold-two simultaneous clearing rule. Direct replay validates returned placement sequences. An independent breadth-first state-set search agreed on 150 seeded target instances: 96 YES and 54 NO, with up to five vertices and eight stacks. Hand cases check fitting without final clearing, clearing that reopens space, occupied-vertex rejection and invalid graphs. An intentionally incorrect candidate returning a feasible one-stack target and always extracting NO-SOLUTION was rejected.

Oracle: CPython 3.12.14 and locked `z3-solver` 4.16.0.0 for the source; standard-library exhaustive search for the target. Only Z3 `unsat` yields source NO; `unknown` raises. The target search is exponential and deliberately limited to finite small instances. The candidate gate checks at most three target placement sequences per source instance, so it does not prove universal recovery. No reduction or solution is claimed.
